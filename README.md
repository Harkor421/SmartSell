## 📖 Sobre el proyecto

Motor de venta reactivo para tokens de pump.fun y pump-swap: se arma a un market cap objetivo y, escuchando el WebSocket de PumpPortal, vende reaccionando a las compras entrantes.

## ✨ Qué hace

- Se arma al alcanzar un market cap objetivo
- Reacciona a las compras en vivo desde PumpPortal
- Soporta pump.fun y pump-swap
- Servidor y fuentes de datos separados
